# Spread The Future — Website

This repository hosts the website for **Spread The Future**, a podcast about the future of Europe.

Static site: plain HTML and CSS, no framework, no dependencies. Hosted on GitHub Pages
at [spreadthefuture.com](https://spreadthefuture.com).
Episode content is generated by a script and committed (see below), so nothing is built
at deploy time.

## Repository layout

```
.
├── index.html              # the site (single page)
├── CNAME                   # custom domain for GitHub Pages, do not delete
├── styles.css              # all styling
├── script.js               # one scroll clamp for the episode accordion
├── episodes.json           # generated episode data, do not hand edit
├── links.json              # hand maintained per-episode platform URLs
├── scripts/build.py        # fetches the RSS feed and generates the episode list
├── assets/
│   ├── logos/              # STF wordmark and favicon
│   └── platforms/          # streaming platform icons
├── archive/                # previous versions of the page, kept for reference
└── .github/workflows/      # RSS to episode data pipeline (manual trigger)
```

## Episodes

Episode content is generated from the podcast RSS feed
(`https://anchor.fm/s/469ddf8c/podcast/rss`), which is the single source of truth.
A GitHub Actions workflow fetches the feed and commits the generated output, so the
site stays fully static. The workflow is triggered manually (`workflow_dispatch`),
so new episodes appear only when someone runs it.
